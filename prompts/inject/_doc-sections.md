# 每轮注入 · 各段怎么来的

> 每一轮对话开始前，`system-prompt/assemble` 事件里追加一段。
> 拼法：`assembled.sections.push({ name: 'memory:inject', text })`

一段注入由六块拼起来：

```
① 说明书      prompts/inject/00-manual.md              ✅ 可改
② 人格段      agents/<你>/人格.md 里抠出来的            ✅ 改人格文件
③ 日记总结    agents/<你>/diary/ 最近一篇的「## 总结」  ✅ 写日记就变了
④ 路标        代码拼的（就两行路径）                    ❌ 不用改
⑤ 话板       prompts/inject/20-board.md                ✅ 可改
⑥ 碎碎念      prompts/inject/99-designer-note.md       ✅ 可改
```

---

## ② 人格段：什么时候给、给多少

这是**最容易搞错的一处**，单独说。

### 给不给完整人格段

| 情况 | 给不给 |
|---|---|
| 这个会话**第一次**注入 | 给全量 |
| 同一个人格，第二轮起 | **不给**（省字数） |
| **中途换了人格** | **给全量**（它换人了） |
| 配置 `persona.repeat = 'every-turn'` | 每轮都给 |

判定代码在 `modules/Inject/index.mjs` 的 handler 里。

**记的是「上次见的是哪个人格」**，不是"见过没有"。

> 之前是 Set（只记见过没）。中途换人格的会话永远拿不到新人格 —— 
> 它不知道自己换了个人。2026-10-28 修掉，现在有测试钉住。

### 反直觉的地方

`seenSessions` 是**进程内**的。**插件重启后，每个会话的"第一次"会再发生一次** —— 
重启后第一条消息，会重新注入全量人格。

这不是 bug，是省事：真持久化要写文件、还得处理"人格文件改过但内容变了"。

### 给多少

从 `人格.md` 抠三块：

| 块 | 怎么找 | 为什么 |
|---|---|---|
| **开头** | 第一个 `---` 之前 | 标题 + 引言 |
| **第一个正文章节** | `---` 之后第一个 `##` 节 | 只取引言的话**连"你是谁"都没有** |
| **红线** | 按关键字找（`/红线/`），不按编号 | 实际在 §十二，不是 §九 |

拼法：

```js
personaText = [intro, firstSection, redline].filter(Boolean).join('\n\n')
```

中间「怎么说话」「评论区怎么回」**故意不塞** —— DSH 的 `AGENTS.md` 本来就会读。

## ④ 路标（代码拼的）

```
你的记忆在 <根>/agents/<你>/ —— 人格、认识的人、日记都在那儿。
忘了什么先翻 INDEX.md，要细节自己去读，别凭着印象说。
```

**为什么这条一直在**：人格段只给一次，之后全靠这一句提醒"你有地方可以翻"。

## ⑤ 话板（有新留言才出现）

文件：`prompts/inject/20-board.md`

```
共享话板有 {{新留言数}} 条新留言（最近：{{谁}}）。要看的自己翻 shared/board.md。
```

**只在 `count > boardSeen` 时出现**，看过就不再提醒。
`{{谁}}` 已经是「名字 · 日期」的格式，模板里别再单独写日期。

---

## 预算怎么砍

默认 2500 字：人格 1500 / 日记 800 / 路标 200。

**超了按「人格 → 日记 → 路标」的顺序砍后面的** —— 人格优先保住，路标最后才砍。

说明书、碎碎念、话板**不参与**这个预算。

---

## 占位符怎么替换

所有 md 文件里的 `{{xxx}}` 会被替换成实际值。

**没给值的占位符原样留着** —— 这样一眼就能看出漏了什么，而不是悄悄变成空字符串。

举例：

| 文件 | 占位符 |
|---|---|
| `inject/00-manual.md` | `{{名字}}` `{{工具列表}}` |
| `inject/20-board.md` | `{{新留言数}}` `{{谁}}` |
| `daily/00-wake.md` | `{{日期}}` `{{昨天没写}}` `{{对话稿路径}}` `{{会话id}}` `{{日记路径}}` |
| `persona/10-bootstrap-command.md` | `{{人格名}}` `{{名字}}` `{{会话id}}` |
