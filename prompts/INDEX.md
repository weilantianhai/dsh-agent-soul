# 提示词总表

**所有对 agent 说的话都在这个目录里，不在代码里。**

改完存盘，下一轮就生效。不用重新打包，不用重启。

---

## 命名约定

- `_doc-` 开头 = **给人看的说明**，不会发给模型
- 其余 = **真正发给模型的提示词**

---

## 哪个提示词什么时候出现

| 提示词 | 什么时候 | 文件 |
|---|---|---|
| 插件使用说明 | 每轮注入 | `inject/00-manual.md` |
| 碎碎念 | 每轮注入（接在说明后面） | `inject/99-designer-note.md` |
| 话板提醒 | 话板有新留言时 | `inject/20-board.md` |
| 日记叫醒词 | 每天晚上 | `daily/00-wake.md` |
| 一键建人格指令 | 点「一键建立」时 | `persona/10-bootstrap-command.md` |
| 人格段 | 会话第一次、或换了人格时 | 从 `agents/<人格>/人格.md` 里抠 |

另外两处不是文件，是代码拼的：

- **路标**（"你的记忆在……"）—— 就两行路径，改的机会极少
- **四个工具的说明** —— 在工具的 schema 里，模型决定调不调工具时读的

---

## 占位符

文件里 `{{xxx}}` 会被替换成实际值。没给值的**原样留着**，这样一眼能看出漏了什么。

| 文件 | 占位符 |
|---|---|
| `inject/00-manual.md` | `{{名字}}` `{{工具列表}}` |
| `inject/20-board.md` | `{{新留言数}}` `{{谁}}` |
| `daily/00-wake.md` | `{{日期}}` `{{昨天没写}}` `{{对话稿路径}}` `{{会话id}}` `{{日记路径}}` |
| `persona/10-bootstrap-command.md` | `{{人格名}}` `{{名字}}` `{{会话id}}` |

---

## 只想改自己那一份

在 `<数据根>/prompts/` 下放同名文件，优先生效。这样升级插件不会覆盖你的改动。

```
memory/prompts/inject/00-manual.md     ← 你自己的版本
```

---

## 人格段是怎么抠的

不是把 `人格.md` 整篇塞进去，只抠三块：

1. **开头** —— 第一个 `---` 之前
2. **第一个正文章节** —— 通常是「一、你是谁」
3. **红线** —— 按关键字找，不按编号

中间「怎么说话」「评论区怎么回」故意不塞 —— DSH 的 `AGENTS.md` 本来就会读。

**什么时候给：**

| 情况 | 给不给 |
|---|---|
| 这个会话第一次注入 | 给全量 |
| 同一个人格，第二轮起 | 不给（省字数） |
| **中途换了人格** | 给全量 |

换人格给全量这条是必须的 —— 不然它不知道自己换了个人。

## 详细说明

每个都有一份 `_doc-` 开头的说明：

- `inject/_doc-sections.md` —— 六段注入怎么拼、预算怎么砍
- `daily/_doc-wake.md` —— 叫醒词的筛子和产出
- `persona/_doc-bootstrap.md` —— 一键建人格的流程和骨架
- `tools/_doc-memory-tools.md` —— 五个工具的原文说明和修改建议
