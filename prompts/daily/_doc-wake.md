# 定时叫醒写日记

> **什么时候发**：每天晚上 `daily.time`（默认 23:30），对筛出来的会话逐个投一条。
> **发到哪**：`sessionController.prompt(..., {kind:'schedule'})` → 界面显示成灰色「自动化任务」卡片，不是主人说话。
> **模板文件**：`prompts/daily/00-wake.md` ✅ **可以直接改**
> **代码**：`modules/Daily/daily.mjs` → `wakeText()`（读文件，读不到才用内置）

---

## 占位符

| 占位符 | 会被换成 |
|---|---|
| `{{日期}}` | `2026-10-28` |
| `{{昨天没写}}` | 昨天没写时是「先一句：昨天（…）你没写。不催，今天照写。」；写了就是空串 |
| `{{对话稿路径}}` | 对话稿的绝对路径 |
| `{{会话id}}` | `session-xxx` |
| `{{日记路径}}` | 日记文件的绝对路径 |

---

## 谁会被叫醒（四道筛子）

| 筛子 | 条件 | 不满足的 reason |
|---|---|---|
| 不是空白 | 说过话 | `blank` |
| 不是子代理 | `origin !== 'subagent'` | `subagent` |
| 不忙 | 当前没在跑 | `busy` |
| 今天动过 | `updatedAt` 是今天 | `not-active-today` |
| 没归档 | 不在归档名单 | `archived` |
| **有人格** | `agents.json` 里有它，且目录真存在 | `no-agent` |
| 人格没被单独关 | `daily.agents` 允许它 | `agent-off` |

「临时会话天然没有名字，一条就筛掉了」说的就是 `no-agent`。

---

## 顺带产出的两样东西

**对话稿**：`agents/<人格>/diary/.draft/<会话>/<日期>.md`

```
# 2026-10-28 · session-xxx

> 这是对话稿，机器筛的：只有谁说了什么，没有当时的温度。

**tianhai**：……
```

只收 `role !== 'assistant'` 的行 —— 只记人说了什么，助手的话不进稿子。

**日记壳**：`agents/<人格>/diary/<会话>/<日期>.md`，建好并写第一行标签：

```
> 会话：<sessionId> · 归属：<agent>
```

她自己写过的，一个字不动。
